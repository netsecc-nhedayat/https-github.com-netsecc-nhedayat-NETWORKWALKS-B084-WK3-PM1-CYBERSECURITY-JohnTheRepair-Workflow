# W3-PM2 — Password auditing with Networkwalks online tools

**Status:** Completed, as reported by the repository author.  
**Assigned objective:** Recover access to the provided Week 3 training PDF using the Networkwalks Hash Calculator and Password Cracker in a web browser.

## 1. Why I did this

The second lab explored a no-installation approach to the same type of password-recovery exercise. Rather than configuring a local application, I examined the browser workflow and how its data handling differs from John and Johnny.

## 2. Tools

- A web browser on Windows (the training also permits other platforms)
- [Networkwalks Hash Calculator](https://networkwalks.com/hash-calculator/)
- [Networkwalks Password Cracker](https://networkwalks.com/password-cracker/)
- The *separate*, authorized training PDF assigned to PM2

## 3. Lab process

1. **Located the assigned training file.** Downloaded the PM2 locked PDF from the designated learning material.
2. **Opened the Hash Calculator.** Supplied the authorized, non-sensitive training PDF to the tool as directed by the exercise.
3. **Prepared the input.** Collected the full `$pdf$...` extraction output used by the Password Cracker.
4. **Started the recovery audit.** Used the Networkwalks Password Cracker interface to test password candidates against the extracted PDF data.
5. **Validated the outcome.** Used the identified candidate password to check whether the assigned PDF could be opened.
6. **Reflected on the risk.** Compared browser-based convenience with the exposure that comes from transferring document material to an external service.

> The module is recorded as completed from the author's statement. This document reconstructs the assigned workflow; it does not claim independent access to the author's run output, successful candidate, elapsed time or screenshots.

## 4. What the experiment demonstrates

The Hash Calculator and Password Cracker split the task into *extracting audit material* and *testing candidate passwords*. A tool's ability to recover a short or common lab password does **not** mean that all password-protected PDFs can be quickly opened. Results depend on the document's security settings, available attack modes, candidate passwords and computational resources.

## 5. Important browser privacy note

This specific exercise intentionally uses a training PDF. An online upload should **not** be used for a personal document, work file, medical record, client data or any sensitive encrypted material without clear permission and a verified data-handling agreement. For real audits, prefer an approved local workflow when possible.
