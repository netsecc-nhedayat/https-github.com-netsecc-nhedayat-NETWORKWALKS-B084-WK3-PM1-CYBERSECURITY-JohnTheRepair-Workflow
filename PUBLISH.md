# GitHub publication guide

This folder is a complete text-based repository skeleton. Its report content was prepared by reviewing the Week 3 **assignment instructions** in the connected Google Drive and the author's statement that both exercises were finished. Personal execution artifacts were not available.

## One-time publishing steps

1. Connect GitHub to ChatGPT if you want a permitted connector-assisted publication, or create the repository manually at [GitHub](https://github.com/new).
2. Suggested repository name: `Password-Security-Labs-Week3`.
3. Public visibility is appropriate only after you inspect the contents and agree to the listed disclosures. You can choose Private first.
4. Use the commands in [`docs/05-publication-checklist.md`](docs/05-publication-checklist.md) to push the folder.
5. Confirm the README and Mermaid diagram render correctly on GitHub.

## Final review

This repository intentionally does not include password-protected PDFs, assignment screenshots, recovered passwords, hash data, personal execution logs or training wordlists. The source guides are credited, not redistributed. Add only artifacts you have permission to share.
